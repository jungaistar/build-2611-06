VPD math & load 데이터 관리

검증 진행에 쓰는 math & load 데이터 가운데 여러 팀이 함께 쓰는 값을 한 곳에서 관리합니다. 양식 엑셀을 올리면 기종 프로젝트마다 팀별 입력 항목이 만들어지고, 누가 무엇을 아직 안 넣었는지 보이며, 팀별 입력 파일을 나눠 주고 되돌려 받아 병합합니다. 자동 계산 칸은 양식의 수식을 그대로 따릅니다. 파일은 브라우저 안에서만 처리합니다.

1. 양식을 올리세요

math & load 데이터 양식 엑셀(프로젝트 생성 · Excalc2D · 필요 데이터 · 실린더 · NVH · Mass 시트)을 올립니다. 시트마다 구분 · 팀 · 파트 · 담당자 · DATA · 단위 머리글과 값 칸을 찾아 항목으로 만듭니다. 양식은 이 브라우저에만 남습니다.

2. 프로젝트

새 프로젝트 만들기

담당자 입력(팀 / 파트)

3. 입력 —

값을 넣고 칸을 벗어나면 바로 저장됩니다. 자동 계산 칸은 양식의 수식대로 채워지며, 참조하는 값이 비어 있으면 「참조 값 대기」로 둡니다.

4. 입력 현황

미입력 목록(팀별 독촉용)

변경 이력

5. 배포 · 취합

팀마다 자기 몫만 든 입력 파일을 내려받아 보내고, 채워 돌아온 파일을 여기에 올려 병합합니다. 같은 칸에 값이 둘 다 있으면 나중에 고친 쪽을 쓰고, 내 값을 지킨 칸은 보고서로 보입니다.

이번 판에서 하지 않는 것

  • 서버 DB — 데이터는 이 브라우저와 내려받은 파일에만 있습니다. 여러 사람이 동시에 고치는 공용 DB 는 사내 서버가 할 일이며, 이 도구는 그 전 단계(양식 → 항목 → 팀별 배포 → 병합)를 맡습니다.
  • 양식 수정 — 항목을 더하거나 빼는 것은 양식 엑셀에서 하고 다시 올립니다(기존 프로젝트는 그대로, 새 프로젝트부터 적용).
  • 복잡한 수식 — 사칙연산 · 셀 참조 · IF 만 따라갑니다. 그 밖의 수식은 「수식 미지원」으로 표시하고 직접 넣습니다.
  • 단위 환산 · 값의 공학적 타당성 검사 — 숫자인지만 봅니다.
